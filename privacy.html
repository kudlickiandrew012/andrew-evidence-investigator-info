Privacy policy

Andrew Evidence Investigator is a personal evidence-review application. This policy describes how its Google API integration accesses, uses, shares and stores information.

Last updated: October 11, 2026.

Information accessed

With the owner's consent, the application accesses the connected account's profile, requested Gmail message and thread identifiers, message headers and text, and requested Drive file metadata and supported text content. The Google permissions are Gmail read-only and Drive read-only. Searches and content reads occur only for the owner's requested work.

Use and transfer

Information is used to retrieve sources, compare evidence, check quotations and prepare private reports. Selected text and provenance are transmitted to OpenAI when the owner starts an agent session. Those sessions are governed by the owner's OpenAI account and the applicable OpenAI service terms and data controls. Google content is not transferred to another connected provider unless the owner explicitly requests that transfer.

The application does not sell Google data, use it for advertising, or use it to train a general-purpose model. Andrew Evidence Investigator's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Storage and access

OAuth credentials for this integration are stored on the owner's Windows computer with Windows DPAPI protection for that Windows user. Credentials are not placed in source control or sent in model prompts. Retrieved excerpts, tool results and reports may be retained in the owner's private local workspace and OpenAI sessions for continuity. The application does not promise automatic deletion after a fixed period.

Owner controls

The owner can stop the local application and revoke its Google access in the Google Account's third-party connections settings. Revocation prevents subsequent authorized Google reads; it does not automatically delete copies already saved in local reports or OpenAI sessions. Those copies and sessions must be removed separately by the owner where desired.
