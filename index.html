Andrew Evidence Investigator

A personal application for reading selected records and producing source-linked evidence reports at its owner's direction.

The application requests read-only access to the owner's Gmail and Google Drive accounts. It can find and read selected messages and supported text documents. It cannot send email, change messages, edit files, share files or delete Google content through these tools.

The local application runs on the owner's Windows computer. When the owner starts an OpenAI agent session, selected retrieved text is sent to the configured OpenAI model to answer the requested question. Account access renews through OAuth; the application does not ask for the owner's Google password.

This application is for its owner's personal use.
